    How it works

    src/sfx.ts checks and compiles a source once, reads the notes of its first cycle and plays them through Tartlet's audio engine. Wiring a sound or calibrated URL clip takes a couple of lines: 

    import { TartletSfx } from './sfx';

const sfx = new TartletSfx();
button.addEventListener('click', () => {
  void sfx.play('setcps(3)\n$: note("e5 b5").s("triangle").decay(.12).sustain(0)');
});

// Import a WAV clip by URL — resampled and retuned automatically by the runtime:
const entry = await sfx.importClip('chime', './clips/detuned-chime.wav');
void sfx.play('setcps(1.5)\n$: note("c4 e4 g4 c5").s("chime").room(.3)');
