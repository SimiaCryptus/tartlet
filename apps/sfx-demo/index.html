    How it works

    src/sfx.ts checks and compiles a source once, reads the notes of its first cycle and plays them through Tartlet's audio engine. Wiring a sound to an event takes one line: 

    import { TartletSfx } from './sfx';

const sfx = new TartletSfx();
button.addEventListener('click', () => {
  void sfx.play('setcps(3)\n$: note("e5 b5").s("triangle").decay(.12).sustain(0)');
});
