    Tartlet runs Strudel-style patterns without ever evaluating code. It is deterministic, sandbox-safe and built for documents. Pick a preset, press play, then start editing.

    How to install it as a ringtone

    Browsers cannot change system ringtones themselves, but installing the file takes a minute:

    • Android: download the WAV (or use Share audio to save it), then open Settings → Sound → Phone ringtone → + and pick the file. Some phones offer "Set as ringtone" when you open the file in the Files app.
    • iPhone: save the WAV to Files, open it in GarageBand and choose Share → Ringtone. On a computer you can instead drag the M4R file onto your iPhone in Finder (Mac) or iTunes (Windows).
    • Notifications and alarms: the same file works; choose it in the relevant settings.
