# Corpus

This is our own corpus, generated by us (idea.md §12.5). It is not published to npm.

- `prompts/generate-prompts.mjs` writes `prompts/prompts.jsonl`: 600 original prompts from
  combined descriptors.
- `collect.mjs` runs prompts against model adapters that maintainers configure locally. Keys
  never enter the repo. Outputs go to `runs/<date>/<model>/<promptId>-<sample>.json` with
  `{ model, date, prompt, sample, output }`.

Corpus v0 exit for G0: the prompts are committed (`pnpm corpus:prompts`), and one
multi-model run is committed under `runs/`.
